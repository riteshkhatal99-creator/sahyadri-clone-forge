# ZameenDhan Property Marketplace

## Goal
Transform the existing Sahyadri-inspired site into **ZameenDhan**, a complete India-focused marketplace for buying, renting, and selling residential and commercial property.

## What will be built
- Rebrand the shared header, footer, colors, copy, imagery, and metadata for ZameenDhan.
- Build a search-led home page with Buy, Rent, and Commercial modes; city selection; property type; budget; and locality search.
- Add curated property cards, city discovery, owner-direct benefits, platform statistics, testimonials, and an owner posting call-to-action.
- Add dedicated pages for property search/results, property details, post-property, commercial properties, and informational links.
- Make search filters and listing interactions work with representative India-based sample properties.
- Preserve the visual qualities the user liked: strong photographic sections, green brand accents, clear section hierarchy, and polished mobile behavior.

## Technical details
- Use TanStack Router route files for each shareable page and route-specific metadata.
- Keep marketplace data in a reusable local data module for this first version; no accounts, payments, or permanent storage are included yet.
- Use locally stored/generated property imagery rather than external hotlinks.
- Verify desktop and mobile layouts, navigation, filtering, forms, console output, and build status.

## Scope note
This delivers a complete polished marketplace experience with demo listings and working front-end flows. User accounts, saved data across devices, owner verification, payments, and live listing storage would require Lovable Cloud as a subsequent phase.
